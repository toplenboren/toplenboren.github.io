ZKP in voting systemsOct 2023

How to choose a name for an event — the core problem of electronic voting, anonymity with a verifiable count, and zero-knowledge proofs in Helios-style systems. U-Camp, Kaş.

Recording (ru) — YouTube

Electronic voting has a fundamental problem: how do you keep every vote anonymous while still letting anyone verify the final count? The talk walks through how zero-knowledge proofs resolve this in Helios-style systems — using the mundane problem of choosing a name for an event as the running example.

Как выбрать название для мероприятия? Базовая задача электронного голосования — анонимность вместе с проверяемым подсчётом голосов. В докладе разбираем, как доказательства с нулевым разглашением решают её в системах типа Helios. Запись на русском. U-Camp, Каш, октябрь 2023.
