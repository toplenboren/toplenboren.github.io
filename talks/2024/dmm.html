Slides (ru)

How to check your XZ version

Run one of these commands. If the version is 5.6.0 or 5.6.1 — roll back:

# Mac
brew info xz
# Debian
dpkg -l | grep xz-utils
# Red Hat
rpm -qi xz
# or
apt show xz-utils

Projects to start with

If you are a student and need open-source experience, pick small projects where someone can mentor you. On mat-mekh these can also count as practical coursework:

slowreader

Open-source local-first RSS reader, TypeScript. Great for beginners.

gitexporter

Utility for copying a repository with submodules. Bash, I mentor.

simple-git-hooks

Utility for installing git hooks in JS projects. I mentor.

Open Condo Software

Open-source property-management platform. I mentor.
